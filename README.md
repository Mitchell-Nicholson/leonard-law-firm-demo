# Leonard Law Firm — Website Demo

Design demo of a homepage for Leonard Law Firm (Metropolis, IL & Paducah, KY).

- `index.html` — the full page, self-contained (logo and headshot are embedded), opens in any browser
- `template.html` — editable source with `{{LOGO}}` / `{{PHOTO}}` placeholders
- `assets/` — original logo and headshot
